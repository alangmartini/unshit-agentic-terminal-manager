### Added

- **New tabs can open on a fresh git worktree.** The command palette (`Ctrl+Shift+P`) gains two commands: **New worktree tab** opens a new tab whose shell starts inside a freshly created `git worktree` of the active workspace's repo (on its own `godly-wt-<hex>` branch, so work done there is easy to merge back), and **Toggle worktree tabs** turns on a mode where every new tab — `Ctrl+T`, the tab-bar `+`, or a workspace's "new terminal" — opens on its own fresh worktree. The mode shows an `on` pill in the palette while active and persists across restarts. Worktrees are created under the app's per-profile `worktrees` directory (the same base Quick Prompt uses). Non-repo workspaces fall back to a plain tab in mode, and the one-shot command explains via toast when the workspace has no git repo.
